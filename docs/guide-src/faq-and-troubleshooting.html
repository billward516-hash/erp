Find your symptom in the table that fits, then read across: what you see, the usual cause, and what to do. Messages are quoted as the system shows them. Some come with a short code in the technical details (for example forbidden); administrators and the people who run the server use these codes, so they are listed too. If your problem is not here, note the exact wording and the reference number, if there is one, and ask your administrator.

Signing in

You seeWhyWhat to do
“Your session has ended. Sign in again.” (401)Your sign-in expired (single sign-on sessions last 12 hours), you signed out in another window, or the token was revoked or never valid.Sign in again. What you were typing is kept as a draft in most forms.
“single sign-on is not set up for example.com; ask your administrator, or sign in another way” (404 sso_not_configured)Your email's domain is not in the company's list, or single sign-on is switched off.Administrator: add the domain and tick single sign-on is on.
“<email> is not a user of <company>; ask your administrator to add you” (403 sso_no_user), sometimes with “the provider did not confirm the email address”Nobody has added you, the email differs from the provider's, the user is inactive, or the provider does not send a verified-email claim.Administrator: check the people import and the email claims.
“this sign-in has expired or was already used; start again” (401 sso_state)More than 10 minutes passed, or the page was reloaded or used twice.Start from the sign-in page again.
“the identity provider answered 4xx” or “did not return JSON” (502 sso_provider)Wrong client secret or redirect address registered, or the provider is down.Administrator: compare the settings with the provider's; try again later.
“the ID token …” (401 sso_token)The provider's token failed a check: wrong client id, unsupported signing method, expired, or the server's clock is out by more than a minute.Administrator and server operator: check client id and server time.
The token you pasted is refused with “invalid or expired token”The token is wrong, revoked, or the company has switched API tokens off.Use single sign-on, or ask the administrator whether tokens are on.
“missing bearer token” (401)A script called the system with no token.Send Authorization: Bearer erp_….

Access and missing menus

You seeWhyWhat to do
“missing permission: work_orders.manage” (403 forbidden)Your roles do not include that permission at that site. The permission name tells you what is needed.Look it up in the Permissions table; ask your administrator for the right role at the right site (scoping).
“<Feature> is turned off for your role. An administrator can turn it on under Admin → Features.” (403 feature_off)An administrator has hidden that area from your role.Ask them to change Features.
“This is part of the Standard edition. Your company uses Lite (books, invoicing, bills, expenses, policies and the intranet); an administrator can upgrade.” (403 edition)The company's plan is Lite, which excludes that area.An upgrade is made by whoever operates your licence (Lite and Standard).
“Field service is not licensed for this site” (402 module_not_licensed)Field service is licensed per site and this site does not have it.Work at a licensed site, or ask for the licence to be extended (Licences). The Field service menu appears only if at least one site has it.
A menu entry you expect is not thereNo role of yours has the needed permission, the feature is hidden from your role, or the entry is for administrators only.Check the two rows above. Some entries show only with a certain permission, such as Reviews, Reminders or Implementation.
You can see a list but not the records or buttonsYou have view but not manage, or your role is granted at a different site.Ask for the right role at the site.
“you cannot approve your own timesheet”, “you cannot approve a request you raised”, “the person who captured an invoice cannot approve it” (422 invalid)Separation of duties: a second person must sign.Ask another approver. In a company where you are the only possible signer and the licence allows it, self-approval is allowed and recorded.

Too many requests, conflicts and the server

You seeWhyWhat to do
“Too many requests. Try again in N seconds.” (429 rate_limited)You, or everyone behind your address, sent more requests than allowed in a minute. Wrong tokens count too.Wait the number of seconds shown. If a whole office is blocked, the server operator should check the proxy setting (Rate limits).
“duplicate value” (409 conflict)You tried to create something whose number or code already exists.Use a different code, or find and edit the existing record.
“overlaps an existing record” (409)Two records of the same kind may not overlap in time, such as two machine states in the same hours.Adjust the dates or times.
“work order is closed”, “request is already …”, “cannot move work order from X to Y” (409)Someone else changed the record first, or the step is not allowed from that state.Reload the page and look at the current status.
“your plan covers up to N properties and N are active; deactivate a property you no longer manage to add another” (409)The property or store licence limit is reached.Deactivate a site no longer in use, or ask for a larger plan.
“a request with this Idempotency-Key is still being processed; retry shortly” / “just finished; retry it” (409 idempotency_in_progress); “used for a different request” (422 idempotency_key_reused)A phone or script retried while the first attempt was in flight, or reused a key.Wait a moment and retry with the same key; use a new key for a different request.
“that breaks a rule on this record (…)”, “a record it refers to does not exist”, “a value is not in the expected format” (422 or 400)A value is outside what the record allows or points at something missing.Correct the value; check that what you refer to still exists.
“not permitted” (403 from the database)The database refused access to a record outside your company or site.Contact your administrator.
“internal error (reference …)” (500)A fault in the server.Give the reference to the server operator; it finds the log entry.
The site will not load; the load balancer reports the server unhealthy; /ready returns 503“N migrations not applied” (an upgrade is half-done) or “database unavailable”.Server operator: run npm run db:migrate or check the database (Upgrading).
A service report was submitted offline and the stop on My day says RefusedThe server applied its rules when the tablet reconnected and refused it: for example the visit was cancelled or reassigned, or the truck did not hold enough of a part.Read the reason on the stop. Correct the report reopens the form with your entries; fix it and submit again, or Discard. See Field service: My day.
A saved service report draft looks empty after a reloadThis was a defect in earlier versions. Now the draft is put back into the form (Draft restored).Reopen the report. If it is still empty, the draft was never saved: check for Draft saved after Save draft.
A rejected change has no Submit for review buttonA rejected change is reworked first: use Rework the change, or Resubmit for review under Screening.See Changes and notices: if a change is rejected.
“material is still issued to this order and not used” when closing a production orderMaterial was issued and neither used by the finished and scrapped units nor returned.Use Return material, or close with a reason for leaving it. See Production orders.
“N change(s) could not be saved” with a Review link at the bottom of the screenWork done offline could not be sent, often because the record changed meanwhile.Open Review and decide for each; see Working offline and on tablets.

Stock, quality and records

You seeWhyWhat to do
“only N of part P on hand at STORE” (422 insufficient_stock)You asked to issue more than the storeroom holds.Receive stock first, correct the count, or choose another storeroom or lot. For lots, the message also says which lots are blocked and why. See Storerooms.
“stock moved after the count was opened for …; recount or confirm to adjust against current quantities” (409 stock_moved)Receipts or issues happened while a count was open.Recount, or confirm to adjust against today's quantities.
“<name> is not qualified to … this asset: CODE (status)” (422 not_qualified)The person lacks a qualification the asset requires, or it has expired.Assign someone qualified, or have the qualification granted (Training).
“N action(s) still open: …” (422 actions_open)A change or review cannot close while actions are open.Finish or cancel the listed actions.
“work order … is … ; it must be verified or closed”, “link the work order that implemented the change first” (422 not_verified)A change cannot be closed until its implementing work is verified and the document or course is updated.Complete those steps; see Changes and notices.
“give the employee 14 days to acknowledge first” (409 too_soon)A review cannot be finalised before the acknowledgement period ends.Wait, then try again.
“X is not a part, location, lot, purchase order or work order here” (404 unknown_code)The scanned or typed code matches nothing in this company.Check the label, or look the code up by hand.
“X not found” (404 not_found)The record does not exist, was removed, or belongs to a site you cannot see.Check the link or number; ask for access if you should see it.

Imports and archives

You seeWhyWhat to do
“N row(s) have errors; fix and re-stage, or commit with allowPartial” (409 import_has_errors)Some rows are invalid and you did not choose to skip them.Download the problems file and fix, or tick Import the good rows and skip …. See Importing data.
“row N failed: …” (409 import_row_failed)A row failed when saving, often because data changed since the check.Check again from the file.
“the rows of this import were removed on … under the company's data retention setting” (410)The import's staged rows were cleaned up.Check the file again from the start.
“licence: N of N users are active, the most the lite edition includes; disable a user or upgrade”The Lite user cap is reached.Operator disables a user, or upgrade.
“a second administrator must confirm a rollback; add another administrator first” (422)A company rollback needs two administrators.Give another person the Administrator role.
“the archive file does not match its checksum” (409 archive_damaged), “… records pointing at missing … records; nothing was changed” (409 archive_inconsistent), “ask the platform operator to run it” (409 rollback_unavailable)The archive file is damaged or cannot be applied cleanly, or the database does not allow rollbacks to be run from the app.Choose a different archive; tell the server operator. Common questions

Why did I not get an email reminder?
Reminders always arrive in the notification bell. In the current build the email digest is prepared but not delivered by any mail service (Scheduled jobs). Check the bell.
Why is a report or approval missing after an administrator changed settings?
A feature may be hidden for your role (Features), or you are not asked to approve records of a feature you cannot see.
Why did my books not update after I approved a bill?
The built-in books post when the accounting sync runs; ask an administrator to press Sync now or schedule it (Accounting connection).
Can I undo a bulk import?
Not with one button. Take an archive first, then bring records back or roll back (Undoing a mistake).
Can I remove someone's access or disable a user?
Not from a screen. Remove them at the identity provider and ask the server operator (Sites and people).
Where can I see what a role can do?
In the Permissions table, and in plain terms under Roles and access.
