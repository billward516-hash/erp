    Administrator brief

    Accounting connection

    Choose between the built-in books and a file export to outside accounting software, run the sync, map accounts and clear items that need attention.

    Administrator brief: more technical, written for the person who sets the system up.

    On this page
    • The choices
    • Set up the built-in books
    • Connect a file export
    • Map the accounts
    • Running the sync
    • Switching or disconnecting

    Invoices, supplier bills and expense reports have to end up in a set of books. This system gives you two real ways to do that: keep the books inside the system (the built-in books), or send bills and invoices to your outside accounting software as a file that you import there. There are no live connections to QuickBooks, Xero, Sage or similar software yet; the page says so. This page describes only what exists today.

    The screen under Admin → Accounting needs the integrations.manage permission, which the administrator and the bookkeeper role hold. Setting up the built-in books itself is done under Books and needs books.manage (the bookkeeper and administrator).

    The choices

    ChoiceWhat it isUse it when
    Built-in booksA small-business ledger inside the system: chart of accounts, journal, bank statement import and matching, reconciliation, period lock, profit and loss, balance sheet, trial balance. Available in both Lite and Standard editions.The company has no accounting software, or wants one system. It is a good fit for small and mid-size companies.
    File exportApproved supplier bills, issued customer invoices, credit memos and approved expense reports are written to CSV files (one file for each kind) that you download and import into any accounting system. Voids are included as VOID rows.The company keeps its books elsewhere.
    MOCK accounting systemA simulated system inside the platform, for demonstrations and testing only. Nothing reaches a real accounting system.Only to demonstrate. Do not use in a real company.

    Only one connection is active at a time. To switch, disconnect the current one first (the built-in books refuse to start while another connection is active, and vice versa).

    The books do not include payroll processing, tax filing, multi-currency, consolidation, fixed-asset depreciation schedules or inventory valuation, in any edition.

    Set up the built-in books

    1. Open Books in the Finance section of the menu and choose Set up the books and fill in your main bank account (name, last four digits), the date and its balance on that date. You get a starter small-business chart of accounts that you can rename or add to.
    2. If the company is starting partway through, what customers still owe on invoices already issued and what the company owes on approved bills and expense reports come in as opening balances, and nothing posts twice. (This is also available later as Bring in open items in the books' settings.)
    3. The previous system's trial balance comes in through Admin → Data import as Opening balances (trial balance); bank statements as Bank and card transactions. See Importing data.
    4. Back on Admin → Accounting you will see a connection named Built-in books, with the counts of items sent, queued and needing attention.

    Entries in the journal never change; a correction is a reversal plus a new entry. Invoices, bills, expense reports and payments post to the journal when a sync runs (below).

    Connect a file export

    1. On Admin → Accounting, with no connection active, the page shows Connect. Choose File export: a CSV of approved bills to import into any accounting system.
    2. Under Approved invoices not yet sent choose Send them with the first sync (backfill everything already approved) or Only send invoices approved from now on.
    3. Choose Connect.
    4. Map your accounts (next section).
    5. To produce a file, choose Sync now. Files appear under Export files with the number of rows; choose Download and import the file into your accounting software. The table remembers when each was downloaded.

    Payment status does not come back from a file export; reconcile payments in your accounting software and record them in the platform's payables, or switch to the built-in books if you want one place.

    Map the accounts

    At the bottom of the page, Chart of accounts lists the kinds of invoice line the platform produces (travel expense, supplies, production materials, freight, capital projects and so on). For each, type your accounting system's Account number and Account name and choose Save. A row shows Mapped or Not mapped. A bill with an unmapped line waits in the queue until its account is mapped, so do this before the first sync.

    Running the sync

    Items are queued when something happens (a bill is approved, an invoice is issued or voided, an expense report is approved or reimbursed) and are sent when a sync runs. Sync now runs one and shows: “Sync finished: N sent, N will retry, N need attention, N payments received.”

    The sync runs once a day by itself. The daily job (Scheduled jobs) runs the sync for your company, with the built-in books or a connected provider, and records it there. If it cannot run, the Scheduled jobs page shows the reason and each administrator gets one notification a day. Once a day is the slowest the ledger can lag; for fresher figures press Sync now or ask the server operator to schedule npx tsx scripts/run-sync.ts (for example every five minutes; each run is safe to overlap).

    The sync queue

    Filter with All, Needs attention, Queued and Sent. Rows say what is being sent: Create bill, Void bill, Create customer invoice, Void customer invoice, Create employee expense bill or Expense reimbursed.

    • A failed send retries automatically after 1, 5, 30, 120 and 720 minutes. After that it waits for a person and shows as Needs attention with the problem in the last column. The reminder Accounting sync problems tells integration administrators daily while any are parked.
    • Choose Retry after fixing the cause (often an unmapped account). Retrying never creates a duplicate: each send carries a unique key.
    • If you entered the item by hand in the accounting system, type how in the box (at least three characters, “Entered by hand as …”) and choose Mark resolved.

    Switching or disconnecting

    1. To move from the built-in books to external software, export the journal (Books → Statements → Export journal), import opening balances into the new system, then choose Disconnect on Admin → Accounting and connect a file export. Events from then on go to the file.
    2. Choosing Disconnect does not delete anything already sent.

    With an external system, that system is the book of record. With the built-in books, the platform is.

    See also Books, Payables and Receivables for the everyday side.
