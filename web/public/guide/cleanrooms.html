    Quality and safety

    Cleanrooms

    Record particle counts, pressure, temperature and humidity in a cleanroom, see them against the room's class limits, and let excursions raise a nonconformance.

    On this page

    • Limits
    • Record a reading

    • The trend chart
    • Import a particle-counter file

    This page is for sites that run a cleanroom and must show it stayed in control. A room has an ISO class (ISO 14644-1). Each room has monitoring points: places in the room where you sample, what is measured there, and how often. Every reading is judged against limits when you record it. A reading over an alert limit tells the room's owner. A reading over an action limit opens an excursion and raises one nonconformance.

    The default particle limits come from the ISO 14644-1 class formula, Cn = 10N × (0.1 / D)2.08 particles per cubic metre (N is the class, D the particle size in micrometres), rounded as in the standard's table. The platform generates them so you can see them; it does not certify them. Confirm them against your own copy of the standard before you rely on them, and set a point's own limits where your procedures differ. The platform does not claim compliance with any standard or regulation: it keeps the records.

    • See rooms, readings, excursions and trends: quality managers and reviewers, operations / plant managers, production supervisors, maintenance managers, technicians, operators, EHS reviewers and executives (permission "view cleanrooms"), at the sites they can see.
    • Record or import readings: quality managers and reviewers, operations / plant managers, production supervisors, maintenance managers, technicians and operators (permission "record cleanroom readings"). Importing a file also needs the data import permissions.
    • Add rooms and points, set limits and sampling frequency: quality managers and operations / plant managers (permission "manage cleanrooms"), and administrators.

    Permissions are per site: a person sees and records only for the sites where they hold the role. Cleanrooms are part of the Standard edition and are not in Lite. An administrator can turn the feature off under Admin → Features.

    Open Quality & safety → Cleanrooms. The page lists each room with its site, class, state, number of points, owner and status. Tiles show open excursions, points whose sampling is overdue, and trends.

    Set up a room

    1. Click New room. Choose the Site, give a Room code (unique in your company) and a Name.
    2. Choose the ISO class (14644-1), 1 to 9, and whether the room is Monitored operational or at rest.
    3. Choose the Owner (told of alerts): an active person with access to the site.
    4. Optionally change Alert limit, % of action limit (default 80) and Trend after this many alerts in a row (default 3, from 2 to 20).
    5. Click Create room, then Add point on the room's page.

    For each point enter Where in the room (for example "P1 Fill line"), Sample every (hours), and tick what is measured there: particle sizes 0.1, 0.2, 0.3, 0.5, 1 and 5 µm (counts per cubic metre), differential pressure (pascals), temperature (°C) and relative humidity (%). Edit room and Edit point change them later; readings already recorded are never changed.

    Limits

    The room's page shows a table of the default limits for its class. Where the standard gives no limit for a size in that class (for example 0.1 µm in ISO 7) that size is not limited, unless the point sets its own.

    • Action limit: the class limit for the size. A count above it is over the action limit.
    • Alert limit: by default the room's alert percentage (80%) of the action limit. A count above it, but not above the action limit, is over the alert limit.
    • Pressure, temperature and humidity have no default limit. They are limited only where you set a range for the point.

    To change them for one point, click Set limits for this point, fill in the boxes for alert and action, below and above, and click Save limits. A box left empty keeps the default; clearing every box in a row goes back to the default. Particle counts have an upper limit only. The alert limit may not be beyond the action limit. A reading is judged against the limits in force when it is recorded; changing limits later does not rewrite earlier readings.

    Record a reading

    1. On the room's page find the point and enter the values you have in the boxes (you need not fill every one).
    2. Check Room was (operational or at rest). Optionally set Read at (blank means now) and a Note.
    3. Click Record reading. A message says what happened.

    Readings cannot be edited or deleted. If one was wrong, record a new one with a note. Two readings for the same point at the same time are not accepted. You can also bring a counter's file in (see Import a particle-counter file).

    What happens when a limit is exceeded

    ReadingWhat happens
    Over an alert limitThe room's owner is told. At most one notice per point per day.
    Over an action limitAn excursion opens at that point and one nonconformance is raised in Quality (major severity), with the room, point, values and limits. The owner is told, and quality managers hear of the nonconformance as usual. More readings over the limit are added to the same excursion; they raise no further nonconformance.
    Back under the action limitThe excursion closes. A later breach starts a new excursion with its own nonconformance. The nonconformance itself is handled and closed in Quality.
    Several alerts in a rowWhen the number of readings in a row at a point over an alert or action limit reaches the room's trend setting, the point is marked trend and the owner is told once for that run. An ok reading ends the run.

    The Excursions table on the room's page lists each excursion with its worst values and a link to its nonconformance.

    Sampling that is overdue

    A point is overdue when its last reading (or its set-up, if it has none) was more than its sampling frequency ago. Overdue points show in the room's page, on What is late under Cleanroom sampling overdue, and in the monitoring report. The daily reminder Cleanroom sampling overdue sends one message per site to the people who record cleanroom readings there and to the room owners. See Notifications and reminders.

    The trend chart

    On the room's page, Trend draws one measure at one point over the last 7 to 365 days, with the action limit as a dashed line. Choose the Point, Measure and Period.

    Import a particle-counter file

    Particle counters and monitoring systems that can export a CSV or Excel file can be read through Data import. Nothing connects to an instrument directly: you export a file and load it.

    1. Set up the rooms and points first. Open Data import (or click Import counter file on the Cleanrooms page) and choose Cleanroom readings (particle counter files).
    2. Choose the file. The importer suggests which column is which. It recognises common spellings such as "0.5um", "0.5 µm", "≥0.5 µm", "DP", "Temp °C" and "RH %". Check the mapping and the preview.
    3. Each row needs a date and time, and a point. Give the room in its own column, or write "room / point" in the point column, or use a point label that exists in only one room.
    4. Counts must be per cubic metre; the file is read as it is. Times are read in the room's site time zone. Temperature is in °C and pressure in pascals.
    5. Commit. Each row is recorded exactly as if you had typed it, so rows over an action limit open an excursion and one nonconformance, and rows over an alert limit tell the owner. Rows are applied oldest first. A row for a point and time that already has a reading is skipped, so loading the same file twice records nothing twice.

    Values for something the point does not measure are ignored with a warning. See Importing data.

    The monitoring report

    Open Reports → Cleanroom environmental monitoring (or the link on a room's page). It shows compliance (readings not over an action limit) by room and week or month, the excursions with their nonconformances, and overdue sampling, and exports to CSV, Excel and PDF like other reports. Use view to switch the table between those three. Its notes repeat that the default limits must be confirmed against your copy of the standard.

    Common mistakes

    • Relying on the default limits without checking them against your copy of the standard.
    • Leaving a size ticked on a point whose class has no limit for it and expecting an alert: it is not limited unless you set a limit.
    • Importing counts per cubic foot or per litre. They are not converted.
    • Expecting pressure, temperature or humidity to alert without setting a range for the point.

    Cleanrooms are a feature of their own (Admin → Features) and a reminder of their own (Admin → Reminders). See Features and editions.
