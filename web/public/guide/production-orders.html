    Production orders

    Plan what to make, release it to the floor, issue materials, and receive finished goods into stock.

    A production order is an instruction to make a stated quantity of one part at one site, by a due date. It follows the part's released product revision: the list of materials per unit and the routing (the ordered operations, each at a work center). This page covers the Production menu's Orders, Products and Work centers tabs. Running the work on the floor is covered in Shop floor and shift log.

    • See orders, products and work centers: anyone with "view production", such as operators, production supervisors, plant managers, quality staff and sales.
    • Create and release orders, edit and release product revisions, add work centers, cancel, complete short, close: production supervisors/planners and plant managers (permission "manage production").
    • Issue materials, receive finished goods, start and stop runs: operators and production supervisors (permission "execute production"), for their own site.
    • Request what is short: needs the purchasing request permission as well.

    Production is part of the Standard edition and can be switched off per company, so you may not see these pages. See the administrator note at the end.

    Where to find it

    Open Production → Production orders. Four tabs run across the top: Orders, Shop floor, Products and Work centers. The three tiles on the Orders tab show open orders, late orders and orders in progress. Tick Only open and completed to hide closed and cancelled orders. Late orders are marked in red.

    What the statuses mean

    StatusMeaningWhat moves it on
    PlannedThe order exists but has no materials or operations yet. Quantity can still change.A manager releases it, or cancels it.
    ReleasedMaterials and operations were copied from the current released revision. The floor can see it.The first run started on the floor makes it In progress. A manager can still cancel it if no material has been issued.
    In progressAt least one run has started.Receiving the full quantity completes it. A manager can complete it short.
    CompletedThe full quantity was received, or the order was completed short with a reason.A manager closes it.
    ClosedFinished and filed. No further changes.—
    CancelledDropped, with a reason. No further changes.—

    A Late tag appears beside any planned, released or in-progress order whose due date has passed.

    Create an order

    1. On the Orders tab, click New production order.
    2. Choose Part to make…. Only parts with a released revision are offered, and the revision number is shown.
    3. Choose the Site, enter the Quantity, and optionally a due date.
    4. Choose Finished goods to…, the storeroom at that site where the made parts will go. You can leave it for later, but you cannot receive goods until it is set.
    5. Click Create. The order opens as Planned.

    If the part has no released revision, the order is refused. Start with the Products tab (below).

    Orders can also come from the plan: the Planned production table on the Planning page has a "create order" link for each part and month.

    Release it to the floor

    1. Open the planned order and click Release to the floor.
    2. The system copies the materials and operations from the part's current released revision. A message tells you whether all materials are covered, or lists the parts that are short.

    The order keeps the revision it was released with, even if a newer revision is released later. If the routing uses a work center at a different site, release is refused; make the order at that site instead.

    Materials: what is short, issuing, and making sub-assemblies

    The Materials table shows, for each part, the quantity required, issued so far, available at the site, and any shortage. Rows with a shortage are highlighted.

    • A purchased part is short: click Request what is short. A purchase request is drafted for the shortfall, less what is already on order or already requested. It opens for you to review. See Purchasing.
    • A part marked "made in house" is short: managers see a Make link beside the shortfall. It creates a new production order for the missing quantity, with the same due date.
    1. In the Materials table, enter the quantity under Issue now for each line. Choose the storeroom if more than one holds stock. For lot-tracked parts, choose the lot.
    2. Or click Fill remaining to propose the quantity still needed, up to what the first storeroom holds.
    3. Click Issue materials. The stock moves out of the storeroom onto the order and appears in Stock movements at the bottom of the page.

    Once some goods are finished, the Variance column shows how actual usage compares with the standard quantity.

    Operations and the shop-floor record

    The Operations table lists each step in order: work center, what is done, quantity received from the previous step, good, scrap and reworked counts, and minutes actual against standard. A linked work instruction opens in the document viewer (see Document control). An operation cannot start until the previous one is finished.

    Operators normally start work from the Shop floor tab. If you are linked to an employee record and allowed to run production, a Start button also appears on the order itself and takes you to the right work center.

    The Shop-floor record lists every run with times, operator, machine, quantities and notes. For a run that scrapped parts, people who may report quality problems see Raise NCR, which opens a nonconformance already linked to the run (see Quality).

    Return unused material

    The Materials table shows, for each line, what was Required, what was Issued to the order in total, what has been Returned, and, on a completed or closed order, what is Left over: issued and not returned, beyond what the good and scrapped units used at standard (quantity per unit with the line's scrap allowance).

    1. Click Return material under the table. It appears for people who may run production, on released, in-progress and completed orders that have material issued.
    2. Choose the material line, the Quantity (on a completed order it starts at the left-over amount; it cannot exceed what is still on the order), and the storeroom at the order's site to Return to.
    3. For a lot- or serial-tracked part, name the lot (or the serial numbers, separated by commas). Left blank, the part goes back as the lot last issued to this order from that storeroom; if you return to a different storeroom you must name the lot.
    4. Give a Reason if it helps (cut shorter than planned, order ended short) and click Return to stock.

    The stock goes back at the cost it left, the line's issued quantity drops, and the movement appears under Stock movements and in the audit trail.

    Receive finished goods

    1. When the last operation has reported good units that are not yet received, a Receive finished goods card appears.
    2. Enter the Quantity to receive. It cannot exceed what the last operation reported and you have not yet received.
    3. If the part is serial-tracked, enter the serial numbers. If it is lot-tracked, the lot is the order number.
    4. Click Receive. The goods go into the finished-goods storeroom at the standard material cost shown on the card.

    When the whole quantity has been received, the order becomes Completed by itself.

    Ending an order early, or closing it

    Managers see a Reason box under the order.

    • Complete short: for an order in progress that will not make the full quantity. A reason is required. It shows on the order afterward.
    • Cancel order: only for planned or released orders, and only while no material is issued to them. A reason is required.
    • Close order: for completed orders. The page shows the material variance in money. Close is refused while material is left over (issued, not returned and not used by the finished and scrapped units): the page lists the parts and quantities. Return the material (see above), or enter Why the material stays and click Close anyway; the reason is recorded in the audit trail with the quantities left.

    An order cannot be completed, in full or short, while a run is still open on it. Stop the runs first. When an order made for a sales order completes, the person who created or quoted that sales order is told it is ready to ship.

    Products and revisions

    A product is a part that has a structure. The Products tab lists parts with their released revision, any draft, and the number of open orders.

    1. To make a new product, type at least two characters of the part number or description under Make a new product and click Start revision 1.
    2. On the revision page click Edit draft. Under Routing add each operation: number, work center, what is done, setup minutes and run minutes per unit. Under Materials per unit search for parts and set the quantity per unit, a scrap allowance (0 to 99 percent) and the operation where it is used.
    3. Click Save draft. Operation numbers must be unique, a part cannot contain itself, and a structure that would loop is refused.
    4. Click Release revision. The routing must have at least one operation. The previous released revision becomes obsolete; orders already released keep the revision they started with.

    A released revision cannot be changed. To change it, click Start revision with the next number, edit that draft, and release it. Only one draft can exist per part. Standard material cost and total run and setup minutes are shown at the top of each revision.

    Work centers

    A work center is a place where operations are done: one machine, a group of machines, or a manual station. The Work centers tab lists them with their machines and how many operations are waiting. Managers click Add work center, choose the site, give a code and name, and tick the machines that can run work there. Leave all unticked for manual work. A work center's code can't repeat at the same site. Click a row to edit it.

    Common mistakes

    • Releasing before the revision is right. The order copies the structure at the moment you release it. Fix and release the revision first.
    • Forgetting the finished-goods storeroom. The Receive button stays disabled without one.
    • Cancelling after issuing. Once material is issued the order can only be completed short.

    Production can be turned off or limited to chosen roles under the features settings. Bills of materials and routings can be loaded from another system with Data import (target "Bills of materials"); they arrive as drafts for review. Scrap reasons are a company list. See Features and editions and Importing data.
