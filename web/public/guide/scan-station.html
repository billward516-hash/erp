    Maintenance

    Scan station

    Receive, issue and count stock on a tablet with a barcode scanner, and print the labels that make it work.

    On this page
    • What you need
    • What the codes mean
    • Receive
    • Issue
    • Count
    • Look up
    • Labels
    • Barcodes
    • Common mistakes

    The scan station is a touch-friendly screen for the storeroom. You receive deliveries, issue parts to jobs and count shelves by scanning barcodes instead of typing. It posts exactly the same ledger entries as the typed screens on Storerooms; it is simply faster and makes fewer mistakes.

    Who can do this: everyone with stock access can open the station and use Look up and Labels. Receive, Issue, Count and Barcodes need the "manage inventory" right (maintenance managers). Someone who can receive purchase orders (buyers) also sees Receive. Technicians with only view access see just the lookup and label tabs.

    What you need

    • A tablet or computer with a browser, signed in to the system, with a connection. The station does not work offline.
    • A USB or Bluetooth scanner that acts like a keyboard, which needs no setup. Or use the tablet's camera where the browser supports it. Or type the code and press Enter.

    Open Maintenance → Scan station. Across the top are the modes. A coloured banner under them confirms each scan, with a beep for success or failure. A wrong scan is refused with the reason, and nothing is posted.

    What the codes mean

    Whatever is scanned is looked up and recognised as one of these:

    ScanWhat it is
    L:CODEA storeroom location. The L: prefix is reserved for our location labels.
    LOT:PARTNUMBER:LOTNUMBERA lot or serial number. The LOT: prefix is reserved for our lot labels.
    A plain part numberA part. Checked first.
    A supplier's UPC, EAN, carton or supplier codeA part, if someone has mapped that code to it (see Barcodes).
    A purchase order numberA purchase order, if you may receive for that site.
    A work order numberA work order, if you may view it.
    A plain location codeA location. This works as a fallback when there is no L: prefix.

    The prefixes exist so a location code and a part number can never be mistaken for each other. Anything unrecognised is refused with "is not a part, location, lot, purchase order or work order here".

    Receive

    1. Choose the Receive tab.
    2. Scan the purchase order. The station shows the order's lines with ordered, received and to-come quantities. If there is no order, skip this step: the screen says "none (receiving without an order)".
    3. If there is no order, scan the shelf location. With an order, each line already knows its storeroom.
    4. Scan the part. Scanning the same part again adds to the quantity (one scan adds the part's "quantity per scan", normally 1). With an order, a part that is not an open line is refused.
    5. Check the quantity, using the minus and plus buttons if needed. For a lot- or serial-tracked part, enter the lot or serial number and, if it has one, the expiry date.
    6. Press Receive. The banner says what was received and how many lines are still open.

    With an order, the receipt is posted against it; without, it is a plain receipt with the reference "Scan receipt". Quantities are limited to what is still to come on the line. Press Clear order to start again.

    Issue

    1. Choose the Issue tab.
    2. Scan the storeroom location you are taking from.
    3. Scan the work order, or type a job, cost centre or line in Job, cost centre or line if there is no work order.
    4. Scan the part. The banner shows how many are on hand at that location, and turns red if none are.
    5. Check the quantity, then press Issue.

    Issuing to a work order records the part on that job, with labor and cost, the same as Record use on the work order. Issuing to a reference is a plain stock issue. The station does not issue lot- or serial-tracked parts: it tells you to issue those from the work order or the storeroom screen, where the lot is chosen.

    Count

    1. Choose the Count tab. The Due for counting table lists storerooms with parts due by schedule.
    2. Either press Count these (or Continue) beside a storeroom, or scan a shelf location to start or continue a count there.
    3. Scan each part. Enter what is on the shelf with the plus and minus buttons or by typing. For a tracked part, choose the lot or serial number. Press Save count.
    4. The list Still to count shrinks as you go. When it is empty, press Finish and post.
    5. If you must stop, press Leave it open and continue later.

    Counts from the station are blind: the screen does not show the expected quantity, so you count what you see. When posted, the banner lists any differences ("Posted. 2 differences: ...") or says everything matched. If stock moved during the count, a red button appears: Stock moved during the count: post against current quantities.

    The count schedule

    A part at a storeroom can be given a count interval in days (up to three years). It becomes due when it has never been counted, or the last count was longer ago than the interval. The station groups the due parts by storeroom. "Count these" opens a count containing only what is due.

    If nothing is listed, no part has an interval set. Set it in Maintenance → Storerooms: open the part at its storeroom and fill in Count every (days) under Reorder and counting settings. Leave it blank to take the part off the schedule.

    Look up

    Scan anything on the Look up tab to see what it is. For a part you get description, unit, whether it is tracked, and where it is on hand. For a location, its code and name (and an Inactive badge if closed). For a lot, its status and expiry. For an order or work order, its status and open lines.

    Labels

    1. Open the Labels tab.
    2. Choose Label for Storeroom locations or Parts.
    3. Tick the rows you want.
    4. Press Print N labels. A PDF opens.
    5. Print it on Avery 5160 label sheets (30 per page, three across).

    Location labels carry the L: code; part labels carry the plain part number. Lot and serial labels are printed from the lot's own page (see Storerooms: a lot's page). A code that cannot be printed as a barcode (letters, digits and punctuation only, up to 48 characters) is refused with a message.

    Barcodes

    Suppliers' cartons often have their own barcode. Map it once and it scans as your part.

    1. Open the Barcodes tab and choose a Part.
    2. Enter the Code (3 to 60 characters), the Kind (UPC, EAN, Carton or Supplier code) and the Quantity per scan (for example, 12 for a carton of twelve).
    3. Press Add barcode.

    A code already used by another part, a part number or a location is refused, and codes starting L: or LOT: are reserved. Remove deletes a mapping.

    Common mistakes

    • Scanning the part before the location in Issue. You will see the on-hand figure only after you have scanned the location.
    • Expecting the station to work with no connection. It needs one.
    • Scanning a supplier carton code that was never mapped. Add it on the Barcodes tab first.
    • Trying to issue a lot-tracked part from here. Use the work order.

    Administrators: give store staff a role with "manage inventory" so they see all modes; see Roles and access. Camera scanning uses the browser's own barcode detector where one exists; otherwise people type or use a keyboard-style scanner. For tablet setup see Offline and tablets.
